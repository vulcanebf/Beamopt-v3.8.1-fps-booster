# Beamopt-v3.8.1-fps-booster
BeamOpt is an experimental BeamNG.drive 0.39.4 performance mod that optimizes mirrors, reflections and PSSM shadows with RAM-only native hooks. Tested gains: DX11 24.5→36 FPS (+47%), DX12 35.8→38.6 (+8%), Vulkan 33.5→35.5 (+6%). Includes auto interior/exterior mirror profiles.
